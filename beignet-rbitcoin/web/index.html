Read before relying on it

  • rbitcoin is young software. Its author calls the mainnet release "early production / high-scrutiny" and "not a Core or Fulcrum replacement", and lists multi-tenant public Electrum service as a non-goal. Use it for your own wallets.
  • x86_64 only. rbitcoin publishes no Linux arm64 build, so a Raspberry Pi Umbrel cannot run it; this page then says the node is not answering.
  • Disk: about 750 GiB for the full store, about 200 GiB of it hot. The first sync takes a day or more. The data is excluded from Umbrel backups and rebuilt from the network.
  • It validates signatures from block 840000 onward (the upstream default milestone); earlier blocks are checked by header chain and transaction structure only.
  • Before 1.0 the on-disk format can change. When an update needs a fresh sync, the release notes say so.
