About this node & operating notes
  • rbitcoin is early production software intended for your own wallets. Public multi-tenant Electrum service is not a goal.
  • This app requires x86_64 hardware such as Umbrel Home. A Raspberry Pi Umbrel cannot run this build.
  • Allow roughly 750 GiB for the full store, including about 200 GiB for the hot store. Initial sync can take a day or more. Chain data is excluded from Umbrel backups.
  • The upstream mainnet milestone is block 840000. Script and signature checks are skipped up to that milestone on the anchored chain. Later blocks are fully validated. Changing validation policy requires an operator-managed configuration.
  • Before version 1.0, an update may require a fresh sync when the storage format changes. Check the app's release notes.
